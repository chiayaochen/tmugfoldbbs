1/21~24行前訓練

　　ㄜ……我好像第一天就遲到……然後到的時候看到大家都在開會了。第二天不知道是
不是因為第一天太累，還是因為教室的二氧化碳濃度稍微高了一點，整個人莫名地不斷陷
入昏迷狀態，連跳舞跳到一半都會睡著……幸好第三天之後就沒有再這樣了。

　　開會(好像到現在我還是有東西沒抄到Orz)、講解教案(講解廟宇的時候似乎真的很容
易睡著，可是我異常清醒，還在那時候記了唯一一次好點)、教舞(老是來不及記)、驗收
舞(幾乎都是靠瓜瓜在旁邊偷偷提醒和眼角瞄同學才過的)、驗收教案(跟哲夫搭吃的健康
，我忘詞有點嚴重)、聯合練習(學長姐有演給我們看，可是第一次看其實並不會記得很清
楚重點有什麼)、聯合營火(定一和定二確實不太一樣，可是也說不出來到底是哪裡不一樣
)……於是行前訓練一下就過去了。

　　有時候還蠻羨慕住宿舍或學校附近的同學，社團活動結束之後一下下就可以回到溫暖
的窩，甚至可以洗完澡然後又跑去楓香廳練到被管理員趕為止；而我要擔心晚上十一點之
後公車會收班，還要擔心我爸可能會衝到學校找我，到了家馬上又被趕去睡覺。家和學校
之間總是卡著那段很討厭的車程，雖然不用繳房租，卻還是會有鄰居的問題。

太亂的時候眾人飛奔到自己座位上收東西的畫面(不過還是照記)，和驗營火舞的時候那個
超經典的「起床」……(「欸欸你剛剛有沒有聽到____『噗！』了一聲？」「沒注意耶…
…」「其實我有發現她趴在桌上很用力在憋笑……」)

　　還有小星夜前，跟我們說要營火總run，我就一直覺得不太對：這一run下去最少兩個
小時如果沒有檢討，而且已經跑過聯合營火了，怎麼可能？然後過沒多久就被叫上樓。門
一開，看到火，頭一個想法是：來真的？居然有火而且在室內耶！可是這火會不會有點小
而且分布太散開了……然後發現被騙了= =|||

　　回到家，把隊長頒的和領來衣服一件一件攤開在床上，寫上名字，重新折起……這時
突然發現，它們很沉重。

過。不過旅伴又是另一批人了。

了。惠農國小的氣氛，對我來說是一種既熟悉，卻又很遙遠的味道。

樣，是稍微按一下就會彈開的種子。有想過要跟他們問清楚那是什麼，但是都沒問(唉，
人老了，連好奇心都沒了)。看到自然科教室裡的水槽被種子堵住，魚缸被種子佔據，我
只一直以為他們只是隨便亂丟玩過的種子……一直到生活媽和我們解釋，我才了解他們是
丟到水裡等它爆開。

　　真的，以前完全沒有看過這種種子，是小朋友給我們上了一堂生物課。


2/01崎峰國小Day 2

　　環境保護，難得一次我在討論教案的時候意見這麼多。那個「夢子」似乎還蠻好強調
個人特色的(雖然我等級沒有很高)。不過小朋友問一問，才發現在這方面自己的知識似乎
還是有一些不清楚的地方。還有，在問問題的時候我發現，那個死小孩頭名叫林強仁的(
臉上有個痣的，人稱「黑點仔」，極少數我記得起名字的小朋友)手上拿了一堆獎品，所
以一直故意跳過他找別人答，除非真的沒有人會。這時候才知道原來他其實知道很多。有
的小朋友可能會說溫室效應和臭氧層破洞有關，因為照到地球的紫外線變多……可是他知
道溫室效應是跟二氧化碳有關而不是臭氧層(因為溫室效應本身這個詞，是指二氧化碳的
保暖能力讓地表形成像溫室一樣，熱能進得來出不去的狀況，跟臭氧層沒有直接相關)。
他讓我想起小時候的自己，皮到快要被老師殺掉，偏偏老是搶班上前幾名。
奧林的天神，因為在弄福爾摩斯，這部分就沒有先排練過，把一大段神射手的自介和跋山
涉水硬是吃掉了……虧我自己還演過魔靶的說>”< 然後放音樂的時機和司儀要莊重這些
也沒做好。

　　福爾摩斯演公公，據說小練習的時候我就是演這個，所以還頗熟的。不過真的要上台
還是要寫台詞，有寫下來真的會比較好背，也比較不會講出一些不合邏輯或是奇怪的話
(ex.你的親生公公)。還記得前一天驗前總驗到快睡著，結果隔天個人關連一次都沒驗過
就要上場了。幸好自己已經在腦袋裡跑過非常多次重點了，該講的大概都有講到，不過第
一次演的時候還是有點卡。我是有拍過桌子啦，可是可能那個桌子做得比較實在，或者是
我剛好敲到有支架的地方，聲音悶悶的而且手超痛，所以我後來都盡量不拍桌子用吼的─
─超傷喉嚨，不過應該還是有嚇到人吧？(我有看到企鵝妳原本差點累到睡著被驚醒……
歹勢啦)然後另一個敗筆是我收太快了，還被小朋友看到我走回去，雖然是有維持用公公
的走法啦不過還是失敗。

　　然後第二梯的營火總run，簡直是瘋到一個境界！特別是繕聯和隊長在鑽那個營火桌
的畫面，那時候是看到沒力氣笑，要是平常就會笑到沒力氣。還有什麼胸部平平花木蘭，
最好是可以用這個啦XD 學長姐似乎有很努力讓我們不要睡著，不過對真的想睡的人似乎
是沒什麼用，特別是像我這種不管什麼姿勢都有辦法昏迷的人。


2/02崎峰國小Day 3

　　傳統故事……那個沖天炮和神鳥超經典的啦！不過你們似乎換衣服換得很累。

　　漂浮娃娃，我自己回家有試過，慢慢少量吸水調重量是可行的，可是連我自己弄都覺
得有困難，幸好學長姐有想出來可以多加一根髮夾。雖然比較浪費髮夾，但是真的簡單很
多。

　　香舞，時間有點不夠沒機會全run一次，不過好像還不錯。剛開始要從小朋友進場一
直蹲著，蹲得頗酸所以一直偷偷在動腳。幸好這一次沒忘記要開始跑。

　　豬尾巴，學長說到離催場一分鐘再去準備，可是還是不夠呀>”< 都沒算到還要調小
麥克風，結果居然空場了。然後那個小麥似乎聲音有點小，後來隊長乾脆拿給我另一隻無
線麥克風，結果變太大聲，一走近主控台就會嗡嗡叫。噢對了，那時候學姐幫我調麥克風
調很久，可是因為麥克風還對著所以沒辦法跟她說謝謝。

　　後來我一直在營火入口，不過這次要讓那裡保持暢通真的是特別困難……


2/03崎峰國小Day 4 + 移動日(屏東→台北)

　　校長教手語，然後演講的時候小朋友居然乖乖聽他講，整個就是不可思議！噢，還有
那個櫻花蝦味道頗不錯XD

　　電視風波，還在想說為什麼沒驗就放我們上台，結果原來是故意的！噢還突然跑出什
麼洗車族，還把價值五千萬的小孩架走……要是阿歪回來的時候沒有及時出聲，那時候我
跟鯰魚差點要直接接ending了！還好後來有ㄠ回來繼續把他演完。

　　忍者，沒驗，可是我們有練歐！不過根本連跳都沒機會跳，直接開始「什麼歌」，最
後連香舞都跑出來了！似乎傳統上最後一天就是要開心一下，不過我覺得對於這個國小的
小朋友其實這一套很適合他們，讓他們看看天下大亂的下場！


= = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = = =

　　其實，我的背包裡還有放日記本，原本是打算萬一有空閒時間要記錄一下。後來回到
家要整理書包時看到，突然覺得自己有點太天真了……XD

　　說到日記，突然想到我們的小日記本好像還收著，而且明天開會據說要帶筆可是不用
帶紙……該不會是要寫出隊後心得吧:P ??


　　噢耶~~終於Po了，我要先去打周公online 啦~XDDD
