: 臺北醫學大學九十二學年度「用愛關懷愛滋-愛的紅絲帶」學生創作設計競賽實施計畫 
: 壹、依據：九十二年九月八日臺軍字第O九二O一一六O九二號函辦理。 
: 貳、目的： 
: 為建構校園愛滋防治安全網，對於愛滋病患與感染者應以「去標籤、去歧視」，
: 真誠、接納與關懷的實際行動，推動愛滋病防治教育。並藉由學生紅絲帶創意設
: 計競賽，以展現「讓自己活，也讓別人活，"Live and let live" 」世界愛滋病
: 日主題，落實「關心愛 滋、全民參與」理念。 
: 參、實施對象：本校全體學生。 
: 肆、實施時間：自即日起至九十二年十月二十日止。作品逕交軍訓室程教官。 
: 伍、實施方式： 
: 一、活動宣傳：透過學校網站之公佈欄、ＢＢＳ、張貼海報公告，並請軍訓同仁於軍
:               訓課中廣為宣導。
: 二、內容規定：紅絲帶創意設計以班級（社團）集體創作為主，主題環繞紅絲帶精神，
:               作品素材、形式不拘，諸如：書籤、海報、動畫、雕刻（塑）、背包、
:               T-Shirt、絲帶等均可，惟設計之作品須能展現愛滋關懷。 
: 　三、評分項目：主題30%，創意25%，宣導效果25%，實用性20% 
:     四、評審編組：由學務長擔任召集委員，學務處各室、組主管及「春暉社」社長擔任評
:                 審委員。 
: 　五、競賽獎勵： 
: （一）校內：第一名（一名）：圖書禮券一仟二百元、獎狀乙幀。 
:             第二名（一名）：圖書禮券一仟元、獎狀乙幀。 
:             第三名（一名）：圖書禮券八百元、獎狀乙幀。 
:             佳作（三名）：圖書禮券五百元、獎狀乙幀。 
: （二）教育部：第一名（一名）：獎金三萬元、獎狀乙幀。 
:               第二名（一名）：獎金二萬元、獎狀乙幀。 
:               第三名（一名）：獎金一萬元、獎狀乙幀。 
:               佳作（二名）：獎狀乙幀。 
: 　陸、作品運用：本校校內比賽最優作品送教育部參加全國決賽，其餘作品配合春暉宣導週
:                 及世界愛滋病日將參賽作品集中展示，以擴大宣導效果。 
: 　柒、參賽作品應遵從智慧財產權之相關規定，不得抄襲、剽竊他人著作，若經查獲，應取

:      「愛滋防治」教育宣導之用。
