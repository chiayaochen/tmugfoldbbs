【 在 AQQ (永遠不會放棄舞蹈) 的大作中提到: 】
: 最近大家或許都在想所謂服務理念吧 
: 但我也發現再次出隊的人  似乎對服務麻痺
: 覺得出隊模式似乎一切都在掌握之中
: 初衷模糊了 
: 而只有不能再出隊的學長姐們
: 夢想著能重溫舊夢 
: 羨慕還有機會再度出隊的基服人
: 為什麼?
: 服務隊到底做了什麼服務
: 還是我們跟救國團的一廂情願?
: 我記得我第一次參加營隊  是在國小三年級
: 那個不是救國團辦的 
: 我記得我好想參加 因為那是我心目中不一樣的世界
: 有我夢想成為那樣的  大哥哥大姊姊
: 還有不同於學校的活動
: 我當時就拿著報名單一直跟我爸爸ㄠ
: 因為其實當時的1000元對我來說真是一比了不起的大數目
: 我真的參加了...
: 營隊當時 我不記得細節了
: 只記得有一整個下午我們泡在都是死昆蟲的游泳池理
: 大部分時間我們都自由活動....
: 當時的我  覺得營隊就是降子嘛  也覺得好玩阿
: 反正不必寫功課就好啦....
: 後來直到高中時我才參加了另一個營隊
: 那是救國團辦的  類似戰鬥營
: 我才真正知道  真正有內容的營隊是什麼樣子的
: 雖然我已經大了  對事物沒有像小時後
: 那樣直接的情緒 那樣純真的沒有自己的好惡評斷
: 但是這個營隊理的每一個人每件事都  讓我好難忘好感動
: 我也覺得  每一格小隊輔都厲害的像神
: 好像都不用休息  好像挖不盡的寶藏....
: 尤其那種共患難的團體好像是遙不可及的夢想
: 說實在的  我跟大部分的人一樣
: 大學之前完全沒想過我會加入服務隊
: 國小對童軍團沒興趣也沒勇氣
: 國高中認為蘭姐只會妨礙我
: 現在的我  一切好像是因緣際會
: 我真的感謝基服.......
: 我想說的只是   現在基服出的隊
: 跟我曾經深深感動過的隊  
: 內容及努力是絕對不會少的!
: 有一天我甚至驚覺  我們甚至不收一文小朋友的錢
: 為什麼我小的時候沒有遇到降的服務隊....
: 驚覺為什麼第一屆學長姐  一點都不怕累 
: 在毫無前例的情況下  覺得降安排是最好的...
: 如果我們知道基服在作的是多麼有意義的事
: 如果我們知道或許在小朋友心中深深烙印
: 如果我們知道一切絕對不是理所當然
: 如果我們知道我們有多幸運  站在前人的肩上  踏著我們一直不自覺的'水準'
: 很多問題根本不需要多說  
: 出隊該做什麼  該說什麼
: 不用擔心我們如何傳達服務理念給學弟妹
: ~~~因為我們就是示範
: p.s自從我去過行講  再加上函屏這一學期在基工打滾的體悟
:      還有我們在寒假去參加別的營隊比較之下
:     我真的很想跟學弟妹說 ~~
: 慶幸自己參加的是''北醫''基服   
: 真的要多多把握  在基服的日子  真的....
:   能夠多付出就不要保留  不管是做事情或是你身邊的人
恩  我也很慶幸自己加入的是北醫基服
自己也在基工小組待了兩期
在當行講工作人員的這段期間  我深深的體認到北醫基服與其他學校的不同之處
不僅是再出隊想法上  還有舞臺觀念,表演技巧方面我們都是他校所推崇的
雖然不敢說是最好  但絕對是屬一屬二的
所以學弟妹可以以自己身為北醫基服的一員而感到高興喔
一直以來我也將我自己加入北醫基服當作我人生到目前為止最正確的決定
我也以身為北醫基服的一員感到驕傲
學弟妹有出隊的機會也千萬要把握住  要不然等年華老去  想出都沒機會了說
也祝福各位在出隊的道路上越走越順....

我還是想說....我愛棒球~~~~
