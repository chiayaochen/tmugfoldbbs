: 隊訓對我們而言是非常重要的
: 可以看到許久不見的優秀學長姐為我們傳授他們的經驗
: 可以學到許多我們尚未學到的東西
: 舉凡營火舞台的搭設
: 人際關係，兒童心理及晚會表演等等
: 每次都覺得自己還有好多要學
: 縱然在這個社團已經待了三年了
: 人家說:學習就要跟海綿一憤
: j勵所有參加隊訓的人希望妳們都是一塊吸收性最好的海綿
: 盡量區吸收學到就是妳的囉！

:   沒錯,許多事情要從做中學,在傳授與學習的過程之中,便有不斷的道理
:   和學問必須要去學習,這就是人生偉大的目的,在求知的過程中需要的不僅僅
:   只是一昧的吸收,還要懂得去擷取你所最缺乏的東西.....
:   在吸收的同時,是否也該思考一下學得的效用,擁有海綿般的吸收力很不簡單
:   但是要擁有老牛般的消化能力,才更加困難,不斷的反芻咀嚼,消化分析,
:   把那些所新得到的知識訊息,轉換成你自己所擁有的東西,那才叫做真學習....
:   希望大家在隊訓的課程中不僅僅只會我們所教的東西,更希望你們能夠把我們傳授的
:   精髓融入自己的東西....這才是我們辦這次隊訓的目的呀~~~~~嗯!大家加油囉!!:)
