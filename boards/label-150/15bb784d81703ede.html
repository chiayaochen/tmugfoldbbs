【 在 mong (我是密斯特史威特) 的大作中提到: 】
: 我想 如果硬要說我們基14有什麼驕傲的地方
: 或許是我們那瘋狂的行為吧....
: 半夜睡不著 電話拿起來就打 一定有人陪你聊天
: 想去貓空或陽明山 不必先約 當天晚上到社窩說了就算
: 要吃宵夜當然更是沒有問題 要吃早餐恕難奉陪
: 要找司機要找工人要找搬家公司要找美工設計要找電腦玩家
: 只要你敢開口 沒有不能解決的事情...
: 甚至事關於一生幸福的事情 我們一定都會當成是自己的事情在處理
: 尤其是我們這一屆有很多基地台跟大喇叭
: 很多訊息傳遞的很快
: 恩?!好吧 我承認我什麼都不太行 我是負責傳遞訊息的 可以了吧
: 在跟各位夥伴之間 有太多太多的點點滴滴
: 無莫靈跟胖多拉最夠朋友 什麼事情都是說走就走
: 尤其是最令人跳腳的三缺一關鍵時刻 他們一定會義不容辭的兩肋插刀說走就走
: 黃正瘋是個好男人 他可以繞很大一圈載女生回家
: 還可以七早八早在某人家樓下等半天 載他一起來學校
: 威霖是器材組腳毛的接班人 他也是個好好先生 被我兇或被我打 他都還是笑笑的喔
: 請注意他的智商沒有問題啦
: 邱阿甘最愛耍帥了 跟他在一起 一定別怕沒有學妹的訊息
: 如果要打聽哪位學妹 更是不作第二人想啊
: 車車跟八弟可以說是保健雙雄 當然不會是說他們的身材很好啦
: 而是說他們真是兩大台柱...各大活動的總召不好找
: 各小活動的總召更是難找 像是基服動感回憶的總召
: 不過在你找不到人的時候 找他們就對啦 他們怎麼會推辭呢??
: 芊卉跟雅婷好像扯不在一起 對吧
: 不不不 這你可就錯了 他們可真是上天安排最好的拍檔呢
: 什麼事情想要跟大家說 但是又不好意思自己出面說的時候
: 就小小聲的跟芊卉講"我跟你說一個秘密喔 你除了雅婷之外誰都不能說出去喔"
: 這樣一來就ok了 保證不到24小時 事情就可以順利的傳播出去了
: 還有阿姨跟點亮他小姐
: 這兩位可是從大一寒假隊就好到現在的最佳夥伴
: 也是基服活力與笑點的來源....更是我冷笑話最好的回應者
: 雅喵是一個很寶的人 也是我大二那一年變胖的主要原因
: 我們會相約著去買東西吃 然後邊吃邊聊天 吃完再去買
: 我們都超愛講話的 一講就是好幾個小時 有幾次還講了六七個小時的話呢
: 還有佾琪 寶萱 心慧 湘雯 貝貝等人
: 天啊 基服要是沒有他們 至少要少掉50%以上的樂趣
: 感謝他們讓我欺負了這麼久 也感謝他們願意在被我欺負之後跟我鬥嘴
: 讓我有棋逢對手的感覺....
: 我還有漏掉誰啊??
: 好像就是這樣了吧.....
: 很感謝你們陪我走過這段日子 也很感謝你們幫我很多忙
: 如果說我會變成今天這樣的我
: 你們真的是功不可沒啊......
: 以後有問題盡量講 不要客氣
: 反正我要去當兵了...
