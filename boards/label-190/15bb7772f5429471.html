對不起不小心就打太長了....

---------------------------分隔線是我 我是分格線-------------------------

看到好多人都來PO了
手癢也好想PO一下 哈哈

畢業的時候學長姊都告訴我
玩過附中就不會覺得大學好玩了
可是我去基服宿營的時候
好開心好開心
我感覺我好像又回到了高中
呆呆的被學長姊唬 哈哈

一開始的團康
好難阿好難阿 我最不會記名字了= =
可是後來的小跑關 推酒瓶 唐伯虎點秋香 打水球 到最後的抽名牌
哈哈每一個都好好玩

在車上 我好想睡覺可是學長姊好嗨一直玩遊戲
塞車塞塞塞 好不容易到了傳說中的崎頂海水浴場
一開始還頗納悶的海到底在哪 = =

然後就是學長姊演戲 
天阿真的是好好笑
後來想到都還會默默偷笑好像白癡(耶~我是白痴= =)

還有下午的大地
我在阿洗學姊的那關濕身了= =
夾錢有X2我們很厲害
解手的大家都是高手 10個人都解出來了 厲害厲害哈哈
汽球碰碰碰實在太不符合人性了= =
英語版的比手畫腳 誰可以告訴我滷蛋便當到底怎麼講...

晚上烤肉 牧晨同學很厲害的為我們解說XD
我們真的有要餵你欸 還叫你一直來吃你都不吃= =
大家很開心的玩竹筍遊戲 別忘了有一個人醜三還沒處罰XDD

晚上真的好嗨 G華酒店加上燈光整個好有FU
音愛好感人 其他戲每齣都讓我捧腹大笑 哈哈哈
晚會好累XD 學長姊辛苦了 
跳舞真的跳到虛脫 脫掉 第一支舞 好害羞 哈哈
(話說下午在練第一支舞的時候我的舞伴太高 
導致搭橋那個動作聽說我的手肘"喀"了一聲...)
還有我怎麼都學不會脫掉那支舞後面轉圈那裡= =

夜教好恐怖 雖然外面煙火好像不用錢的碰碰碰
但我還是低著頭什麼都不敢亂看= =
左右的男同學你們的手很痛吧SORRY..
我們這組什麼任務都沒完成= = 連眼睛都沒有矇
最後面的學長姊對不起害你們尷尬了>"<

洗澡 雅如同學偷偷回去聊天
我竟然會被"媽媽朋友的小孩"給唬了嘖嘖
然後是睡覺 一整夜沒睡= =
好想看星星一定很漂亮 哈哈

隔天是令人SHOCK的身世大解謎
我想我的表情一定非常之好笑= =
怎麼會有這種事 而且我前幾天才看過"雅如同學"的照片欸
還有點歌時間很酷欸我喜歡

再來是海海海海 是我最喜歡的海
賭場好嗨好嗨 重點是"十八啦"為什麼大便學姊甩一點我都會一點阿
這是什麼世界 大家都賺錢只有我沒有O口Q...
還有可愛的小妹妹參加我們的中秋節特別活動 XD
我想他一定愛上基服了 哈哈

後來的濕身遊戲我都沒玩到(／‵⑸′)／~ ╧╧
也不能跟大家在海裡打滾 可惡阿可惡
明年一定要玩到 哈哈

最後還是要來一支舞
不是鬼 我是豬~
我跟阿歪是啪特呢 好累好累到底跳了幾次 = =
不過我們最後一次的轉圈圈有成功呢 厲害厲害耶耶

回到北醫不免要來的咕嘰咕嘰
我想之後只要聽到這首歌這些美好的回憶一定會跑出來:)

謝謝學長姊讓我人生中第一個宿營這麼好玩
我明年一定要參加 因為我答應小妹妹明年要繼續跟他玩XD
還要教他用寶特瓶吹出聲音XD 
重點是我想把這種快樂讓下一屆也感受到 哈哈

耶~我愛北醫基服 我愛第一小隊:D
