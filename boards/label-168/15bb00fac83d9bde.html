【 在 AQQ (異鄉人) 的大作中提到: 】
: 看到大家對巡迴對熱烈迴響
: 覺得真的很棒 
: 社團就是靠醬子的溫暖在前進
: 但是 我們要好好思考一下巡迴對到底要做什麼
: 不然很容易大家只是去看看逛逛 塞塞小卡
: 會不會變成對對上的一種打擾
: 所以 要去巡迴隊的人
: 一定要是在經驗上 對務問題處理
: 或是當天營火 給予實際幫助
: 但是我們不是""直接代替"他們的幹部
: 一到就馬上下去做事 
: 醬子其實對幹部成長沒什麼幫助
: 所以 我希望巡迴對以三年級以上的人去  
: 二年級以下 如果你真ㄉ很想幫助他們 你可以把你想說的話
: 寫在小卡上 或是你想做的事告訴我們
: 所以  要去巡迴隊的人  我們也要再討論一下 該怎麼幫
: 巡迴對對於隊上成員的鼓勵也是很重要的
: 出隊的人看到團內的人來  自然比較有安全感
: 但是 絕對不是只有我們這些巡迴對在關心他們
: 所以 請大家都抽空寫一些對他們有幫助的東西
: 我相信再出隊時  可以收到你的鼓勵一定是最有幫助的
: 巡迴對可以做到的一定很大
: 我們可以考慮一下出隊的人員
: 平時了解他們的人提供一下意見
: 再給他們最需要的協助

      就像怡如所說的巡迴隊能給的是實質的幫助鼓勵....

      而非去探望關心而已...

      但精神上的鼓勵與支持是最需要的...所以大家努力寫小卡吧^^

      另外,千萬不要打擾到該隊既定的流程與情緒....

      巡迴隊本應來無影去無蹤....有種暗中幫助的味道...

      給予適度的協助與建議相信才會進步與成長

      過度的介入與命令反而會造成隊上困擾

      所以希望大家藉此機會能了解到巡迴隊的目的與功用....
  
      也期盼各位出隊的夥伴能夠自力更生...

      沒事也儘量不要打電話給出隊的夥伴...

      以免造成隊上的困擾^^

      巡迴隊加油囉~~~最好是先分配好工作...

      今年的巡迴隊我大概去不成了...不過我的精神與你們同在唷!!!*^^*
