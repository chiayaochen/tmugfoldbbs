       以下言論非關社團評鑑
       只是個人己見
       這一點是我必須再三強調的           
: :       第一，事前有這種想法的話，
: :       是不是只要用拿第二的心態去面對一切挑戰
: :       反正比我好的多的是，我再怎麼做也拿不到第一
:           我就是無法想像為何有如此消極的想法出現
:           凡事只在一念之間
:           作任何事情  最重要的就是那關鍵時刻的想法
:           何必自己先洩自己的氣呢
:           要懂得給自己該有的掌聲阿
            先存了拿第二的念頭
            凡事退而求其次
            不正是洩自己的氣嗎？
            如果得失無動於衷
            第一和第二有什麼差別？
: :       只以第二為目標
: :       能有穩拿第二的把握嗎？
:           就是因為沒有
:           更要虛心求教  百尺竿頭更進一步
            位居第一也是可以虛心求教
            那拘泥於第二未免不知變通
            只有第二才會謙虛嗎？
            說不定以為自己不過一人之下、萬人之上
            而自大成狂 

            說真的
            我們看金馬獎或奧斯卡金像獎時
            每一個獎項的得獎人都是理所當然的
            而沒有讓人出乎意料之外？ 
            或多或少有吧！
            但是又能如何？
            做了該做的事
            別人能不能給予相等的肯定
            畢竟非己能決定
            得獎之後
            高興也罷，失落也罷
            這不是一個結束
            也不是一個開始
            如果把得獎當目的
            為了得獎而作改變
            比方說
            下一次的評審喜歡壯闊史詩般的大製作
            籌拍的計劃便此為主
            不是一個導演想拍的題材
            可是為了得獎而拍電影
            一開始的出發就不同
            沒有得獎不是一切都完了     
            
            甚至有時候獎項會扼殺一個人
            因為他再也無法超越得獎的自己
            只有結束自己的生命

            往往你做的事並沒有一個獎可以頒給你讓大家知道
            母親很辛苦，然而能夠成為楷模而得獎的幾多？
            這代表得獎的母親比較優秀？
            我想不會有人會如此想
            自己的母親永遠都是天下第一等

            我並無意在獎不獎的問題上打轉
            得獎不是那麼重要

            但老二哲學令我覺得反感

            不求第一，便不必求第二，便無所求 

            僅僅如此而已
