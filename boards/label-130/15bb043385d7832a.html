【 在 lighthee (什麼是什麼) 的大作中提到: 】
: 像之前文傑說的(還是偉武說的?)啊
: 和一起出隊的夥伴重溫基服出隊的回憶
: 讓大家感情更好也更愛基服這個地方
: 才是隊聚最深刻的意義
: 至於吃什麼玩什麼只是附帶的囉
: 重要的是和大家在一起的感覺嘛
: 就算只是在大安森林公園吃魯味玩嚕牌
: 也是很棒的隊聚呀 ^^
 :恩  其實每一次出隊之後能夠全隊在聚在一起的機會真的不多
 所以每一次辦隊聚總是希望全隊的人都能夠到齊
 大家一起聊聊天呀什麼的  或者再提起當年出隊時隊上有趣的事
 這種感覺真的很棒說
我想今天不在於隊費所剩多寡吧
如果今天這個隊的感情很好  就算隊費沒有了 自己掏腰包也是很樂意不是嗎?
能夠辦隊聚真的是一件很幸福的事情唷.....



 【 在 saxo (爵士照相看星星還有學電腦而且不可不用功) 的大作中提到: 】
: : 最近看大家都紛分在隊聚
: : 可是好像以前到現在都是先po在板上直街先說了再問大家說可不可以
: : 有點像是公告的樣子
: : 最近可能也是從我們隊上開始有公告的樣子
: : 在這邊跟大家說聲抱歉
: : 不過要讓大家知道的是
: : 在我們隊上工告隊劇之前
: : 百分之九十的人都以經確定可以來了
: : 我才會讓大家知道
: : 一方面再次提省大家也可以讓其它的人知道
: : 希望隊聚的主辦人不要就冒然的po出來然後壹才發現一大堆人都不能去
: : 而又逼的要改期或是只有少少人去隊聚而喪失當初想要隊聚的動力或意義
: : 在這邊也有一個很重要的事情想說一下
: : 隊聚的心態決對不是去"花錢"
: : 不是比誰去吃的貴或誰家隊長請的多
: : 請大家想想
: : 為什麼總是希望能夠全隊到齊
: : 一個隊從隊長出任開使直到出完隊~~
: : 它的意義就結束了嗎~~
: : 或許隊聚的真正意義就在其中......
