: 雖然今天不是很多時間再做深入的交流
: 但是我們大家都會深信著這麼做是有他的意義在得
: 經過這一次大家彼此的熟悉
: 有希望大家不要荒廢及浪費了這一次活動的目的
: 如果你們有任何疑問都是歡迎大家隨時去分享
: 服務的意義會在之後你們更加熟識的過程中
: 在我們之間進行交流
: 這就是我們辦這個活動的意義
: 未來或許會有更多的服務性社團有機會讓我們一起交流
: 而這個機會是我們要自己去創造
: 期望在接下來你們的成長階段
: 都是有很多夥伴的參與
: 也期望我們能夠一起將服務傳播到每一個角落
: 每一個服務員一同分享快樂及心得
: 一起加油囉~

趁機會報一些沿革給大家知

我的話很多
我要先講校外

幾年前救國團還有舉辦"行前講習"
行前講習(行講)是救國團辦給基服隊的訓練課程
所有承辦基服隊的社團都會派人參加

    有的學校(比如說輔大) 就是和北醫一樣 
        有"基層文化服務社"或"基層文化服務團"這樣的社團來承辦
    有的學校裡承辦的社團可能是某一個服務性社團
        (比如說 銘傳大學就是由"弘仁社"在承辦)
    總之就是 全國的很多學校的不同社團都會去參加


基十二文傑就是在這個機會下認識實踐 輔大 銘傳的夥伴
然後就締結姐妹社 接著 我們就生出了"四基而動"
當時的想法是想把四基而動逐步擴展為小型的行講
讓多一點學校來參加 讓北區的學校有交流的機會

也幸好有四基而動
讓我們在行講停辦的現在 還能繼續維持和外校交流




然後我要講校內

學校課外活動組有舉辦"社團負責人研習營"
幾年前的社團負責人研習營裡有討論到服務性社團彼此之間的交流
本來是有人建議在學期中借個場地辦交流活動
讓校內所有的服務性社團 包含醫療隊 都一起來參加
很可惜的是 後來就沒有下文了

後來基十二元志有給我們一個想法是
校內的服務性社團這麼多
我們如果能夠共用資源
比如說一起辦一個課程 一起找老師
那不是可以用更少的資源 達到更好的效果

其實校內服務性社團很多 所以交集並不好找
我們當時想到的是
雖然各服務性社團的走向大不同
但其實大部分社團都有對於"衛教"的需求

所以我們曾經和綠十字 一起找了家醫科醫師來講衛教
我們也曾經請疾管局的老師 也有邀請康輔山服大家都來參加
但可惜的是時間並不好配合
所以後來幾年也沒有繼續下去



"康on let's fun 山基" 是很好的開始耶 加油囉
